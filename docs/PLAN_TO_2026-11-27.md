## Constraints that shape "all channels"

**YouTube Data API quota: 10,000 units/day, shared by every channel.** A backlink or title apply ≈ 51u
(`quota.APPLY`). After syncs, polls and `YT_QUOTA_APPLY_RESERVE` (1,500), roughly **130 applies/day fit
fleet-wide ≈ 10/channel/day**. 13 × 40 would need ≈ 26k. The ledger gate (`quota.can_afford`) already skips rather
than overspends, but caps should be set deliberately (e.g. Marathi 25, others ~8). Shorts uploads aren't charged to
the ledger (`app/shorts/youtube_upload.py`): check real burn (`quota_log` query in STATE §8) before widening. A quota
increase from Google takes weeks: not before 11-27.
