after syncs and polls ≈ 130 writes/day fleet-wide. `YT_QUOTA_COLLECTION_RESERVE` (3,000u) stops writes early so
the day's syncs keep room; the ledger gate skips rather than overspends. A Google quota increase takes weeks.

catch-up reruns missed daily jobs). Avoid restarts 14:30–16:45 IST on Mondays (weekly jobs).

## How to work

- Office steps: the owner runs blocks from `docs/agents/office-runbook.md` (gitignored) and pastes the log; review
  it, then give the next step. Every block starts with `[Console]::OutputEncoding = [Text.Encoding]::UTF8`, uses
  `$PSItem` and `count(1)`, writes to `logs\*.txt`.
- Previews before any switch-on: `docker compose run --rm --no-deps -T -e PYTHONPATH=/app midas python -u
  scripts/preview_titles.py|preview_backlinks.py --channel <id> --n 12` (read-only, new image without a restart).
- Migrations: `scripts/apply_migrations.py`, then `docker compose restart postgrest rest`; NAS snapshot after any
  DB change (CLAUDE.md).
- Code: branch → PR → merge (main is PR-only); CI builds the image on every merge.
